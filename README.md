# Zyraa Kitchens - Web Application Prototype

A high-fidelity, interactive, single-page web application prototype built for **Zyraa Kitchens**, a premier multi-brand cloud kitchen network based in Bengaluru, Karnataka, India.

---

## 🌟 Key Highlights & Architecture

- **Interactive State Machine**: Implemented with React `useState` hooks handling dynamic cart additions, quantity steppers, item deletions, real-time aggregate billing calculations, sliding drawer controls, and brand category filtering.
- **Design System & Palette**:
  - **Dark Slate Charcoal** (`#111827` / Tailwind `bg-gray-900`) for navigation, footer, and brand contrast.
  - **Warm Saffron / Amber** (`#F59E0B` / Tailwind `text-amber-500` / `bg-amber-500`) for CTAs, appetite simulation, and accent highlights.
  - **Light Off-White** (`#F9FAFB` / Tailwind `bg-gray-50`) for comfortable readability in menu sections.
  - **Geometric Modern Sans-Serif**: Google Fonts (*Plus Jakarta Sans* & *Outfit*).
- **Culinary Assets**: High-resolution photorealistic imagery for all virtual brand signature dishes and dramatic hero commercial kitchen backdrop.
- **Real-Time Delivery Engine Simulator**: Interactive location check for Bengaluru hubs (*Koramangala*, *Indiranagar*, *HSR Layout*, *Whitefield*, *JP Nagar*).
- **Interactive Checkout Modal**: Complete order dispatch simulation with live kitchen tracking stages.

## 🚀 How to Run Locally

You can run this application immediately using any standard web server or by directly opening the file:

### Option 1: Python HTTP Server (Recommended)
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`

### Option 2: Node.js `npx serve`
```bash
npx serve .
```

### Option 3: Direct File Open
Double-click `index.html` in your file explorer to open directly in Google Chrome, Microsoft Edge, or Safari.
